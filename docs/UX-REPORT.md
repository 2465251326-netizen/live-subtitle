# 模拟用户体验报告（R6：CBS 英语新闻·当前配置实测）

> 归档时间：2026-09-11 凌晨 · 报告人：模拟用户（团队角色）· 处置人：产品经理
> 场景：以用户当时的真实配置，浏览器打开 CBS Evening News（2026-09-09 完整播报）实测。
> 版本：v2.3.1（源码运行）。所有数字来自真实命令输出，可复现。

## 一、体验前配置自查（= 设置页逐页看）

| 设置 | 值 | 判读 |
|---|---|---|
| 识别模型 | medium | ⚠️ 重模型 |
| 计算方式 | **cpu** | 🔴 机器有 RTX 2060（6GB），重模型硬跑 CPU |
| 翻译引擎 | argos（离线） | ⚠️ 直译腔，新闻术语错译放大 |
| 代理模式 | **none（直连）** | 🔴 在线引擎（Google）必不可达 |
| 悬浮字幕条 | 关 | 🟡 核心功能被自己关掉且无提醒 |
| 连续流/流式上屏/幻觉抑制/热键 J·O | 开/开/开/开 | ✓ |

## 二、实测数据（同一条新闻，三个窗口取样）

| 取样 | 结果 |
|---|---|
| 挂机 18 分钟 | 缓存 +162 条（≈9 条/分钟），队列常满 |
| 60 秒窗口 | **+3 条** |
| 视频从 0 重播 · 干净 90 秒 | **+8 条（5.3 条/分钟）**，而新闻需要 ≈27 条/分钟 |
| 内容位置 | 视频播到 ~1:30 时，字幕仍在翻译 ~0:30 的开场蒙太奇 → **滞后约 1 分钟且持续扩大** |
| 正面项 | `pipeline.no_segments_15s` 23:18:37 准时触发；J/O 热键正常；全程无崩溃 |

## 四、产品经理处置

- **归因**：体验差 ≈ 配置组合（medium+CPU+argos+直连），非代码缺陷；但"应用对错误配置零反馈"是产品缺陷。
- **裁决**（用户授权"问你了产品经理"）：五项配置变更 `large-v3-turbo / cuda / auto / system / 悬浮条开`，改前备份 `~/.live_subtitle/config.json.bak-20260910_235823`。
- **代码侧**（先于本报告发布于 v2.3.1）：重模型+CPU 常驻预警横幅；纯标点垃圾段滤除；引擎探测失败原因落日志（`translate.probe_failed`）。

## 五、处置后验收（R7，同视频同流程）

| 指标 | R6（旧配置） | R7（新配置） |
|---|---|---|
| 引擎 | argos 直译 | **google 在线**（代理恢复后自动选上） |
| 模型就绪 | 3.1s CPU | **1.87s CUDA** |
| 90 秒新增（缓存） | 8 条 | 15 条（热缓存命中多，实际吞吐更高） |
| 滞后 | 滚雪球（1 分钟+） | **稳定在管线深度约 30~60 秒，不扩散** |
| 译文 | "无处可去的人" | "他们正在直接奔向自我完善的超级智能。" |
| GPU | 闲置 | 11% / 2.9GB |

**结论：通过。** 截图存证 `%TEMP%\ls_e2e_s9_ux_final.png`（人眼验收用）。

## 六、本报告遗留的产品缺口（未立案，待裁决）

1. **悬浮条被关闭后无任何再提醒**：用户关了就忘了，主窗空页面可加一行状态提示（如"悬浮字幕条：已关闭（Ctrl+Alt+O 可随时打开）"）。
2. **代理=none 且所选引擎依赖在线时，无事前警告**：现在只有事后日志（probe_failed）；可在开始翻译时探测失败即出横幅"在线引擎不可达，已回退 XX——代理设置在「设置-通用」"。
