# LiveSubtitle · 实时字幕翻译

对标 Chrome「实时字幕 (Live Caption)」的独立桌面程序，并补齐它的短板：**自动识别语言 + 实时翻译成中文**。

- 抓取系统正在播放的声音（网页视频、播放器、会议软件），也可用麦克风
- 离线语音识别（本地 Whisper 模型），自动检测说话语言
- 双翻译通道：在线免费接口（默认）+ 离线语言包（Argos），可随时切换
- 深色主窗口字幕记录 + 可拖动的置顶悬浮字幕条
- 全部字幕本地生成，识别缓存持久化，相同语句秒回

## 技术方案

| 环节 | 方案 | 说明 |
|------|------|------|
| 音频捕捉 | pyaudiowpatch (WASAPI loopback) | 直接抓系统输出声音，无需立体声混音设置 |
| 语音分段 | 能量 VAD（自适应噪声底） | 静音 0.45s 切句，单段最长 14s |
| 语音识别 | faster-whisper | CPU int8 即可实时；tiny/base/small/medium 可选 |
| 在线翻译 | Google gtx 接口（免 Key） | 失败自动降级 MyMemory |
| 离线翻译 | Argos 语言包（CTranslate2 直载） | 界面内一键下载，内置推理无需 torch |
| 界面 | PySide6 (Qt6) | 深色玻璃风格 + 悬浮字幕条 |

## 快速开始（Windows）

### 方式一：打包成安装程序（推荐）

1. 安装 Python 3.10 或 3.11（勾选 Add to PATH）
2. 双击 `build_installer.bat`
   - 自动完成：创建构建环境 -> 安装依赖 -> PyInstaller 打包 -> 检测 Inno Setup（未装则通过 winget 自动安装）-> 生成安装程序
3. 得到 `dist\installer\LiveSubtitle-Setup-1.0.0.exe`，双击安装（带桌面快捷方式与卸载器）

### 方式二：绿色版（免安装）

1. 双击 `build_exe.bat`
2. 运行 `dist\LiveSubtitle\LiveSubtitle.exe`

### 方式三：不打包直接运行

```bat
pip install -r requirements.txt
python main.py
```

崩溃排查：程序崩溃日志写入 `~\.live_subtitle\logs\app.log`（含未捕获异常与 Qt 致命错误）。

## 使用步骤

1. 左侧选择音频源：**系统声音**（看视频选这个）或麦克风
2. 选择识别模型（首次会自动下载，推荐 `small`，中文更准）
3. 翻译引擎默认 **Google 免费接口**，离线场景切换到 **Argos** 并下载语言包
4. 点右上角「开始翻译」，播放视频即可
5. 需要悬浮字幕时勾选「启用悬浮字幕条」，鼠标拖动到播放器下方，右键可关闭

## 翻译引擎说明

- **自动探测（默认）**：启动时自动测试 Google 与 MyMemory 的连通性（各 2.5 秒），选用可达者。国内网络会自动落在 MyMemory，海外网络自动落在 Google。会话期间一旦主引擎失败降级到备援，后续直达备援、不再重复等待超时
- **Google 免费接口**：无需注册、无需 API Key、无每日额度。国内网络被墙时探测会自动避开它
- **MyMemory**：免 Key，每天约 5000 字符额度，国内可达
- **Argos（离线）**：首次下载语言包后完全离线工作，断网可用，隐私最佳，也是重度使用（超 MyMemory 额度）的长期方案

三个在线通道都不需要申请任何 Key。

## 深度测试结论（2026-09 实测）

| 测试项 | 结果 |
|--------|------|
| 自然人声中文：语言自动检测 | 检测 zh，置信度 1.00，转写逐字正确（small 模型） |
| 自然人声英文：语言自动检测 | 检测 en，置信度 1.00，转写逐字正确 |
| 引擎自动探测 | Google 不可达时 3 秒内自动落 MyMemory 并翻译成功 |
| 中文输入跳过翻译 | 原样输出，零网络请求 |
| 重复文本缓存 | 命中后 0 网络请求，持久化重启有效 |
| VAD 边界 | 纯静音/低电平噪声不误触发；20 秒连续语音强制切割；0.2 秒噪声丢弃 |
| 连续语音噪声底 | 已修复：长语音下阈值自适应失控导致后半段字幕全丢，改为仅静音时跟踪噪声底 |
| 队列延迟保护 | 弱机器/慢识别时丢最旧保最新（实测 5 段保 3 段最新），字幕不滞后堆积 |
| 停止时丢字幕 | 已修复：停止时清空积压队列，不再有线程强杀丢数据 |

注意：tiny/base 模型对中文的识别与语言检测明显偏弱（合成语音会误判），中文场景请用 small 及以上。

## 离线语言包

离线翻译已内置（CTranslate2 推理，无需额外安装任何依赖），语言包在应用内一键下载：

1. 「翻译引擎」选择 **Argos 离线语言包**
2. 下拉选择源语言（如 English），点击下载（英文包约 70MB，含进度条）
3. 下载一次后永久离线可用，识别（本地 Whisper）+ 翻译（本地语言包）全程断网可用

语言包安装到 `~\.live_subtitle\argos\packs\`，索引自动从官方源获取（GitHub raw + jsdelivr 双源自动切换）。

## 识别模型选择建议

| 模型 | 体积 | 单条字幕延迟 | 中文准确率 | 适合 |
|------|------|------|-----------|------|
| tiny | 75MB | ~2s | 差（语言易误判） | 纯英文 + 老电脑 |
| base | 145MB | ~2.5s | 差（语言易误判） | 纯英文 |
| small | 480MB | ~3s（4 核以上） | 良好 | 默认，推荐 |
| medium | 1.5GB | ~6s 或需 GPU | 优秀 | 高配电脑 |

延迟构成：VAD 切句 0.45s + 转写（Whisper encoder 固定 30s 帧成本，与段长基本无关）+ 翻译（离线 0.1s / 在线 0.5-2s）。
实测数据（int8 CPU，语言锁定后）：真实桌面 4 核 RTF 约 0.5-0.8（实时跟得上）；双核老机器建议 tiny/base。

模型缓存在 `~\.live_subtitle\hf\`，下载过一次永久离线可用。国内网络下载慢时，启动前设置环境变量：

```bat
set HF_ENDPOINT=https://hf-mirror.com
```

## 常见问题

- **抓不到系统声音**：确认选择的是当前正在发声的输出设备；蓝牙耳机类虚拟设备部分不支持回环，切换「刷新设备列表」重选
- **识别延迟高**：换 tiny/base 模型；关掉其他占 CPU 的程序
- **有 N 卡想加速**：识别设备选「自动（优先 GPU）」，并安装 CUDA 版 PyTorch 环境（可选）
- **完全离线使用**：识别模型本地运行 + Argos 语言包，安装完成后可拔网线
- **Google 提示限流**：正常现象，会自动走 MyMemory；也可以手动切到 Argos 离线包

## 稳健性设计（v1.0.1 审查后加固）

- **语言记忆不会死锁**：自动模式下语言检测置信度低于 0.6 的段落丢弃并重置记忆，下一句重新检测（换语言视频无感切换）；手动锁定语言时始终按选择输出
- **延迟不会雪崩**：识别队列上限 3 段、翻译队列上限 5 条，积压时自动丢弃最旧，字幕始终贴近当前播放进度
- **启动不卡顿**：网络探测（HuggingFace 可达性）全部异步，模型加载前才同步等待
- **崩溃可诊断**：未捕获异常与 Qt 致命错误写入 `~\.live_subtitle\logs\app.log`
